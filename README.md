📋 Описание
HardwareMonitor — приложение для комплексного мониторинга аппаратного обеспечения ПК.
Получает данные о процессоре, оперативной памяти, дисках, видеокарте, сетевых адаптерах и системной информации через технологию WMI (Windows Management Instrumentation) и отображает их в удобном интерфейсе на базе WPF.
Разработано в рамках лабораторной работы по дисциплине «Системное программное обеспечение».

🎯 Цель лабораторной работы
Разработать WPF-приложение для комплексного мониторинга аппаратного обеспечения с использованием WMI и паттерна MVVM.

✅ Задачи

Освоить работу с WMI в C# через библиотеку System.Management
Получать данные об аппаратном обеспечении: процессор, память, диски, GPU, сеть
Реализовать обновление данных в реальном времени без блокировки UI
Разработать интерфейс с использованием WPF и паттерна MVVM
Освоить многопоточность (async/await + Task.Run) для фоновых WMI-запросов
Реализовать экспорт данных в форматах TXT, CSV, JSON
Обеспечить обработку исключений и отзывчивость приложения


⚙️ Функциональность

Модель, количество ядер и логических потоков

Процент использования

💾 Диски

Логические диски: буква, общий объём, свободное место (DriveType=3)

Название видеоадаптера
Объём видеопамяти (выбирается адаптер с максимальным AdapterRAM)
Текущее разрешение экрана

🌐 Сеть

Список физических сетевых адаптеров
MAC-адрес, статус подключения, скорость

🖥 Система

Название и версия ОС, архитектура
Имя компьютера и текущего пользователя

📤 Экспорт

Экспорт полной информации о системе в .txt
Экспорт данных в формате .csv (открывается в Excel)
Экспорт данных в формате .json для программной обработки

🔁 Автообновление

Настраиваемый интервал обновления (в секундах)
Возможность отключить автообновление через чекбокс
Строка статуса с временем последнего обновления

🚀 Как использовать

⚠️ Запускай приложение от имени администратора — часть WMI-счётчиков (загрузка CPU, данные GPU) требует повышенных прав.


Открой проект в Visual Studio 2022
Восстанови NuGet-пакеты (Restore NuGet Packages)
Запусти проект (F5 или Ctrl+F5)
Данные загружаются автоматически при старте
Переключайся между вкладками: Процессор / Память / Диски / Видеокарта / Сеть / Система
Нажми «Обновить» для ручного обновления данных
Настрой интервал автообновления в поле «Интервал (сек)»
Кнопки «TXT» / «CSV» / «JSON» сохранят отчёт в нужном формате
Кнопка «?» откроет подробную справку по программе
